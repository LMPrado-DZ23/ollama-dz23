# Notas dos mockups

`configuration-mockup.png`, `builder-mockup.png` e `mobile-mockup.png` são imagens conceituais criadas para comunicar a direção visual do Ollama Classe A+. Todas contêm rótulos de conceito na própria imagem e no texto inferior para evitar que sejam confundidas com telas funcionais já entregues.

O mockup de configuração representa a futura consolidação visual de runtime, conectores, segurança e publicação; nesta revisão, a configuração real é feita por API e variáveis de ambiente. O mockup de builder representa o canvas e o fluxo de publicação que estão parcialmente implementados; drag-and-drop e componentes ricos ainda precisam de evolução. O mockup mobile representa a direção do companion Expo; a base de missão, approval e sincronização offline existe, mas push remoto, conflitos avançados e distribuição nas lojas ainda não são considerados concluídos.
